# Youssef Errachid - Portfolio

![Portfolio Preview](./public/images/profile.png)

Welcome to the source code for my personal portfolio! I'm Youssef Errachid, a Full-Stack Developer specializing in building exceptional digital experiences. This portfolio showcases my journey, skills, and the projects I've built.

## 🚀 Tech Stack

This portfolio was originally built with pure HTML, CSS, and vanilla JavaScript, and has been successfully migrated to a modern **React** application powered by **Vite**.

*   **Framework:** [React](https://react.dev/) + [Vite](https://vitejs.dev/)
*   **Styling:** Vanilla CSS (Custom design system, CSS Variables)
*   **Animations:** [GSAP](https://gsap.com/) (GreenSock Animation Platform) for complex sequences and native CSS for micro-interactions
*   **Deployment:** [Netlify](https://www.netlify.com/)
*   **Form Handling:** Netlify Forms

## ✨ Features

*   **Interactive Hero Section:** Dynamic typewriter effect and a custom GSAP-powered logo scramble animation.
*   **Custom Micro-Interactions:** Smooth scroll-reveal animations using Intersection Observer logic and an ambient mouse-tracking glow effect.
*   **Project Showcase:** Dynamic filtering system to sort projects by technology (Java, JavaScript, C++).
*   **Responsive Design:** Fully fluid layout that works seamlessly across desktop, tablet, and mobile devices with a custom off-canvas navigation menu.
*   **Functional Contact Form:** Built-in form using Netlify's serverless form handling.

## 💻 Local Development

To run this project locally, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Youssef-Errachid/portfolio-website.git
    cd portfolio-website
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Start the development server:**
    ```bash
    npm run dev
    ```

4.  **Open in your browser:**
    Navigate to `http://localhost:5173`

## 📂 Project Structure

*   `public/`: Contains static assets like images and the CV file.
*   `src/components/`: Reusable React components for each section of the page (Hero, About, Projects, etc.).
*   `src/hooks/`: Custom React hooks for animations (`useReveal`, `useTypewriter`).
*   `src/index.css`: Global styles and design system tokens.
